# CheckFiber

## Sobre o projeto
Sistema de checklist de materiais desenvolvido
para empresas de telecomunicações.

## Funcionalidades
- Login do operador.
- Cadastro e exclusão de materiais.
- Preenchimento do checklist pelo técnico.
- Histórico de conferências.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript

## Hospedagem
O projeto está hospedado no GitHub Pages.

## Limitações
O sistema não possui integração com banco de dados.
As informações são armazenadas localmente no navegador.
